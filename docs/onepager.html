The problem

A capacity problem that's really an information problem

Wards lose bed capacity not because patients can't leave, but because the reason they're stuck is buried in prose. WardBeat makes that legible in real time.

Invisible barriersA patient is medically fit but stuck on meds, transport, social care, or a review — and no one has one current view of why.

Signal buried in notesDischarge status and blockers live in free-text nursing and ward-round notes, not structured fields.

Reactive, not plannedBed managers firefight in the afternoon; discharges that could happen before noon slip.

Design decisions

The choices an interviewer will probe

✓

Grounding over trust

Every barrier cites its source sentence; unverifiable model output is dropped, never shown. In healthcare you show the evidence.

↔

Mock ↔ live by one flag

Same /extract contract runs a deterministic offline extractor or real NIM — and the mock is the fallback if a call fails, so the board never breaks.

◎

Measured, not assumed

An eval harness scores extraction F1 against labelled ground truth. It caught a bad first model choice and drove the prompt from 69% → 88%.

⊣

GenAI where it belongs

The LLM does language → structure and reasoning. Forecasting and optimisation are classical ML/OR — deliberately not an LLM's job.

Why NVIDIA NIM

The deciding factor for clinical data

NIM microservices are self-hostable containers with an OpenAI-compatible API. The demo runs on the free hosted tier; the identical code redeploys on-prem inside a hospital's own GPUs — so patient-adjacent data never leaves the trust. That data-sovereignty path is the reason a hosted frontier API can't win here.
